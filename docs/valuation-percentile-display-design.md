# 估值详情：分位展示统一方案

## 目标与范围

统一估值详情顶部摘要、图表参考线、悬停分位、下方统计的表达。沿用当前三列收益摘要和五个走势入口，不改后端计算，不把历史位置解释为交易建议。

## 展示规则

- PE/PB：低分位绿色，高分位红色；股息率/股债差/股债比：低分位红色，高分位绿色。
- 低分位为 <30，中间为 30～70（含边界），高分位为 >70。中间和缺失使用中性色。无效或缺失数值显示 —，不拼接单位、不产生颜色判断。
- 顶部三项当前值使用正常文字色；5 年分位及历史位置文字使用上述方向颜色。历史位置为“历史偏低 / 历史中间区间 / 历史偏高”，缺失为“暂无分位”。PB 五年分位同样遵守方向规则。
- 保留当前值、5 年分位、5 年均值。股债差当前值及均值单位为“百分点”；股债比为“倍”；股息率为 %。辅助信息允许换行，不截断为省略号。
- 图表默认近5年；顶部固定5年统计。图表旁明确“近N年历史分位”，并注明图表分位按所选窗口计算、顶部固定五年，历史不足以实际样本为准。
- 30/中位/70参考线按主指标方向配色。标签统一在绘图区左端内侧向右展开，有主题背景，不与外侧Y轴文字重叠。不增加右侧留白。
- Tooltip 写“当日分位（近N年窗口）”，仅主指标显示分位。它是当前窗口内的回看排名，不是历史当日向前滚动排名。继续保留当前窗口的中间秩算法，有限数值参与，缺失/NaN/Infinity排除；样本排序缓存，避免每次鼠标移动排序。上方服务端分位算法不变，文案明确统计来源可能不同。
- 下方股息率/股债统计中的固定绿色当前值、固定绿色进度条取消：当前值中性，进度条按同一方向规则颜色。统计明确各自窗口；股债差/比均值和当前值带正确单位。
- 主题适配复用现有颜色变量及 chartTheme；计算颜色方向由独立工具函数管理，图表通过明确 props 获取方向和窗口，禁止靠中文标签猜测指标类型。

## 三、已定稿口径速查

| # | 口径 | 值 |
| --- | --- | --- |
| 1 | 建仓日 T0 | **2013-04-26** = 各标的**数据可得区间**的共同起点。**不引入"成立日/上市日"外部元数据**（用户 2026-09-19 裁决：回测起止日 = 数据起止日；个股无此接口） |
| 2 | 「成立来」起算 | 自 T0 起算。韭圈儿自成立日面值起算 → 差 **1.27pp**（口径差异，非误差），该格容差 ±1.5pp |
| 3 | 起点规则 | **共同**：`T_start = max(用户选择, T0)`，更早日期**自动前移** |
| 4 | 复权口径 | **分红再投日增长率链式**（蛋卷 `percentage`），禁用单位净值 |
| 5 | 账本 | **份额法**：`n_i = w_i / P_i(T0)`，`NAV(t) = Σ n_i·P_i(t)` |
| 6 | 区间查询 | 取净值序列两点比值，**不重置权重** |
| 7 | 再平衡 | 只支持 **不平衡 / 季平衡 / 年平衡**（韭圈儿无月/阈值选项） |
| 8 | 交易成本 | **不计** |
| 9 | 交易日口径 | **并集 + 前值填充** |
| 10 | 近1日 | `Σ wᵢ × rᵢ(各自最新可用日)`（QDII 前值补偿） |
| 11 | 相关性 | 日涨跌幅皮尔森，交集对齐，**计算区间独立于回测区间** |
| 12 | 完整曲线模式 | **不做**（起点规则互斥 + "空仓"语义未验证） |
| 13 | **再平衡/基准/区间的归属** | **属于 `backtest_run`（参数即身份），不属于 `portfolio`**。组合只描述"持有什么、各多少"。`portfolio` 可存 `default_*` 仅作预填 |
| 14 | **组合范围** | **支持多组合**（用户可创建多个）。**L1 组合列表**（管组合：新建/进入/复制/改名/删除）+ **L2 组合详情**（复刻韭圈儿，管标的与回测）。⚠ "多组合 → 单组合"指的是**页面层级**（列表 → 详情），不是数量收敛 |
| 15 | 组合内标的重复 | **禁止**（唯一键 `(portfolio_id, symbol)`） |
| 16 | `added_at` 位置 | **成员表**（同一标的在不同组合添加日不同） |

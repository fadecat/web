# 需求：转债行情页（B1 转债中位数走势）

> 状态：已由系统实施方案替代；原稿保留作需求追溯，不再作为开发验收标准。
> 实施依据：[转债市场系统设计与实施方案](superpowers/plans/2026-09-10-cb-market-system-design-and-implementation.md)。
> 参照物：转债行情日报 2026-09-09 里的图「可转债价格中位数与平均收益率」

## 1. 要做什么

新增一个网页页面，把日报里那张图搬到网站上看，并且比日报强：

- 静态图片 → 交互图表（可缩放、可看每天的数值）
- 固定全历史 → 可切换时间窗口
- 日报只有一张图 → 页面可以看更多指标（同一批数据里有现成的）

## 2. 页面设计

- 路由：`/cb-market`，名称「转债行情」，放进导航「转债」组（和转债筛选、选债因子并列）
- 页面主体是一张双轴折线图：
  - **左轴（蓝线）**：价格中位数（`median_price`），和日报图一致
  - **右轴（橙线）**：平均到期收益率（`avg_ytm`），和日报图一致
- 时间窗口切换：**全历史 / 10 年 / 5 年 / 3 年**（默认全历史，本地数据本来就只有 8 年多）
- 图下加一段当天的数字摘要（取最新一行）：价格中位数、平均收益率、成交额、温度、转债只数——对应日报顶部的「市场概览」块
- 移动端适配：跟随估值详情页的已有做法（图表自适应宽度、上下布局）

## 3. 数据来源（不用新抓数据）

- 表：`cb_index_daily`（已有 2106 行，2017-12-29 ~ 今，任务每日自动更新）
- 接口：**复用现有的** `GET /api/cb-index/daily`，全量返回所有字段，后端不用改
  - 数据量约 200KB，可接受；之后嫌大再做按窗口裁剪
- 本次只画 2 条线，但接口里还有现成字段（平均/中位溢价率、平均双低、平均价格、转债只数、温度），页面预留了加线的可能，本期不做

## 4. 明确不做的（本期边界）

- 不做指标切换 Tab（溢价率、双低等以后单独加）
- 不做和其他指数的叠加对比
- 不动日报生成逻辑

## 6. 验收标准

1. 打开 `/cb-market` 能看到全历史双轴图，形状和日报图一致（蓝线 95~145 区间、橙线当前约 -10%）
2. 时间窗口切换正常，图表自适应手机宽度
3. ECS 部署后公网可访问，数据比本地新（ECS 每日任务在更新）

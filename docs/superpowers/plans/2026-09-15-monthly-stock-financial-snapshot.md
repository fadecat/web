# 月度正股财务快照实施说明

## 范围

每月在北京时间 02:00-05:00 低峰窗口抓取集思录高股息全市场数据，首次部署由调度器在次日凌晨启动。快照独立于每日 `stock_dividend_daily`，在完整抓取并通过数量、重复代码和失败请求校验后发布。转债选债列表按正股代码展示集思录来源的 `profit_average`（当前源字段名称为“利润均值”，尚未证明等于归母利润同比，页面不得擅自改写口径）。该列不进入筛选因子、评分或排序。

## 调度与发布

`stock_financial_monthly` 每天 02:10 检查，任务函数仅允许在 02:00-05:00 执行，并按 `snapshot_month + SUCCESS` 幂等。首次运行自然安排到创建后的下一个凌晨窗口。抓取使用既有 `fetch_dividend_snapshot(min_total_value=0)`，请求限速由集思录网关和账号池负责。

当前实现以一个全量抓取批次作为最小可发布单元，并将批次状态、数量、请求数、失败数和源交易日持久化；后续若单次窗口需要强制切片，应在抓取器暴露查询分片游标后扩展，不能在调用方另写 HTTP 或登录逻辑。失败批次不得替换最近成功批次。

## 数据关联

`StockFinancialSnapshotBatch` 保存批次元数据，`StockFinancialSnapshot` 保存结构化字段和 `raw_json`。转债查询只关联最近成功且 `source_trade_date <= as_of_date` 的批次，避免历史结果使用未来财务数据。接口返回 `stock_financial` 命名空间及 `financial_snapshot_date`、覆盖数和缺失数。

## 验收清单

- 每日高股息表和页面数据不受月度全量影响。
- 无成功批次或失败批次时，转债列表继续显示 `—` 或上一个成功批次。
- 代码匹配使用六位股票代码，空值与负值可正常展示。
- 页面列名和说明明确标注集思录口径，不宣称为原始财报同比。
- 月度财务字段不出现在因子目录和模板条件中。

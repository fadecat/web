# 做T策略实证研究 · 600900.SH（长江电力）

日期: 2026-09-18
样本: 2023-09-18 ~ 2026-09-18，725 个交易日
代码: `scripts/t_sim_core.py`

---

## 1. 研究问题

长期持有一类下跌空间相对有限、波动相对稳定的股票（红利 / 低波 / 央企），能否利用底仓，
通过日内或短周期波动反复做 T，长期降低持仓成本？

原始设想：把 research 模块的三档买卖位当作**限价单定价器**（不是择时预测器），
收盘后据此下次日隔夜单；买单先成交则立刻挂卖单，卖单先成交则立刻挂低吸买单（成交触发反手）。

T+1 不构成约束——投资者持有长期底仓，做 T 的目的是摊薄成本而非净卖出。

---

## 2. 研究目标漂移与修正

第一轮研究出现了明显的目标漂移。识别出的 10 个问题中，以下三个是致命的：

| # | 问题 | 修正动作 |
|---|---|---|
| 1 | **目标周期错配**：用 FV20（未来 20 日平均振幅）衡量做 T 机会，但做 T 的持仓周期是 1~10 日 | ① 改为订单级事件研究：hit / rebound / MAE / MFE / 回复天数 |
| 2 | **Oracle 不是真正上界**：所谓 Oracle 实验没有固定资金约束，K 的对比不公平 | ② 改为固定底仓、固定 K、固定成本下的 Perfect Information Test（VPI） |
| 3 | **底仓没有真实建模**：`sim_K` 用净头寸近似，未显式建模股数与成本 | ③ 改为显式 inventory model：分侧额度、真实佣金/印花税、除权处理 |

其余问题（全样本分位数的 look-ahead、OHLC 路径未知、振幅定义、FV20 样本重叠、
反复试因子 K、成本模型过于简单）在本轮一并处理，方法见第 4 节。

**原则：修正目标变量、回测约束与 Oracle 上界之前，新增因子的意义有限。** 因此本轮不引入任何新因子
（成长-红利收益差、股债比、股息差、PE 百分位等一律暂缓）。

## 3. 数据基础

- 行情：通达信 `period=4`，`tqFlag=0`（不复权）与 `tqFlag=2`（后复权）双序列
- 计划：research 模块 `/api/research/replays/{run_id}/days`
- 缺失 K 线 3 根，用 research 的 `next_open/high/low/close` 补全
- 区间后复权总回报 **+30.12%**，年化 **+9.23%**

### 3.1 复权因子必须自建（关键陷阱）

research 模块返回的 `scale` **不是复权因子**：它有 452 个唯一值、几乎每天变化、区间 0.409~0.448。
直接拿它做换算会污染全部 PnL。

正确做法：用不复权与后复权双序列反推分段常数因子 F。

```
除权日判据:  |hfq_ret − raw_ret| > 1.5%
F 为分段常数, 归一化到 F(last) = 1
```

识别出的真实除权日：**2024-07-19 / 2025-07-18 / 2026-07-17**（每年 7 月，符合长江电力分红节奏）。
用 `hfq_close / raw_close` 直接算会产生 21 个假除权日（舍入噪声）。

### 3.2 档位表达

档位以「距 T 日收盘的百分比距离」表达：`buy_dist = (close_T − level) / close_T`。
该表述与复权方式解耦，换任何复权口径结论不变。

## 4. 方法

### 4.1 目标变量（修正①）

废弃 FV20，构造 **1479 笔挂单**的订单级数据集（65.2% 在 10 日内赚到 δ），指标为：

- `hit`：maxhold 内是否触及反手目标
- `rebound`：成交后是否向有利方向回复
- `MFE / MAE`：最大有利偏移 / 最大不利偏移
- 回复天数

#### 配对 + DiD（必须做）

挂单价本来就低于收盘价，所以「从入场价算 +1%」天然比「从收盘价算 +1%」容易。
这个**机械效应会伪造出一个巨大的假 lift**。

设计：同一天、同一窗口，比较

```
P(目标达成 | 从入场价起算)  −  P(目标达成 | 从 T 日收盘起算)
```

差值（DiD）才是真实的择时能力。

#### 重叠窗口的显著性

FV20 / 10 日窗口逐日重叠，普通 bootstrap 会严重高估显著性。
改用 **block bootstrap，block = 20 日**。

### 4.2 Oracle 上界（修正②）

同底仓、同 K、同成本、同占用，只放开信息，测三种 Perfect Information：

- `oracle='trend'`：完美方向过滤（只在方向对的一侧挂单）
- `oracle='fill'`：完美选单（只挂一定会赢的单）
- `oracle='delta'`：完美反手目标 δ

训练/测试切分：60% @ **2025-07-15**，参数只在训练段选。分位数用**滚动扩展窗口**，杜绝 look-ahead。

### 4.3 库存模型（修正③）

```
shares ∈ [BASE_SH − Ks·U,  BASE_SH + Kb·U]
约束:  #未平买循环 ≤ Kb,  #未平卖循环 ≤ Ks     ← 分侧计数, 不是净头寸
```

**只约束净头寸会让买卖两侧同时无限累积。** 这是初版的 bug：shares 一度跑到 −15000 ~ +38000，
期末净空 −7000，收益被虚增。修正后期末 `inv = +0`。

成本模型：

```
c = max(名义 × 费率, 最低佣金)      # 最低 5 元
if 卖出: c += 名义 × 印花税
```

PnL 在后复权（总回报）空间计算，使分红不污染成本收益；真实价格 = hfq / F，用于成本核算。

路径保守假设：只有开盘价已越过挂单价才认定当日成交（`path_opt=True` 放开）。
另加成交缓冲 `buf`：价格需额外穿透 `buf` 才算成交，用于刻画排队 / 滑点 / 不成交。

## 5. 结果

### 5.1 不存在可预测的均值回复（最重要）

配对 DiD 后，条件命中率相对无条件命中率的 lift **全部塌缩**：

| 档位 | DiD lift | 95% CI（block bootstrap） |
|---|---|---|
| 买1（H=10）| +2.8pp | [−1.7, +7.7] |
| 买2（H=10）| +1.1pp | 跨 0 |
| 卖1（H=5）| −0.8pp | 跨 0 |
| 卖2（H=5）| −2.0pp | 跨 0 |

条件远期收益 vs 无条件远期收益同样全部跨 0
（买1 H=10 为 −0.253pp，卖1 H=5 为 −0.280pp）。

> **此前观测到的 +10~32pp lift 几乎全部是入场价机械效应。** 这是本研究最大的一个认知修正。

### 5.2 信息价值是 10 倍量级，但不在波动率里

固定资金约束下的 VPI：

| 情形 | 年化 | vs 基准 |
|---|---|---|
| 基准（全挂）| 2.38% | — |
| 完美方向过滤 | 7.38% | +5.00pp |
| **完美选单** | **24.62%** | **+22.24pp** |
| 完美反手 δ | 32.14% | +29.76pp |

动态 K + 完美机会认知：+22.14pp，且平均占用反而更低（2.08 vs 2.59）——佐证此前 K 的对比确实不公平。

而我们能拿到的：自身历史特征（HV5/20/60、ATR14、ret5、ret20、rng1、z-score）
**样本外 AUC 仅 0.51~0.64**；最好的可执行过滤器（剔除 20 日涨幅最高的 1/3）
只捕获 **+0.47pp = VPI 的 2.1%**。

符号不稳定：ret20-high 训练 +0.50pp / 测试 +0.43pp（一致）；
HV20-high 训练 −2.37pp / 测试 +1.43pp（**不一致**）。

### 5.3 单笔经济结构

526 个循环：

| 组成 | 占比 | 单笔 |
|---|---|---|
| 触及目标 | 68% | **+1.30%** |
| 强平 | 32% | **−2.13%** |
| 往返成本 | — | **−0.10%** |
| **净** | | **+0.10%/单** |

× 176 单/年 = 底仓市值的 **2.38%/年**。

### 5.4 两条死亡线

- **成交缓冲 buf = 0.10% → −1.04%/年**。排队 / 滑点假设一加就死，说明收益对成交质量高度敏感。
- **单笔 < 500 股（名义 < 1.4 万元）→ 转负**。5 元最低佣金下，200 股的往返成本高达 22.7bp。

### 5.5 止损是价值毁灭

0.8% ~ 3.0% 各档全部为负（−2.7% ~ −4.8%/年）。
原因：做 T 的收益依赖等待回复，提前砍单等于砍掉赢家。

### 5.6 通道比参数重要

| 通道 | 年化 |
|---|---|
| A 股 万2.5 + 印花 | 2.38% |
| A 股 万1 + 免5 | 3.04% |
| ETF / 可转债 万一、免印花 | **4.13%**（对应 2.675 元/股） |

### 5.7 训练 / 测试诚实性检查

| 段 | 年化 | VPI |
|---|---|---|
| 训练（至 2025-07-15）| 4.27% | +23.25pp |
| 测试 | 0.83% | +20.74pp |

两端同为正，VPI 在样本外同样成立——**信息价值是真的，只是我们拿不到**。

### 5.8 最佳参数

δ = 1.3%、K = 3、maxhold = 10 日、U = 1000 股。
δ < 0.8% 时收益被成本吃光转负；δ = 2.0% 仍为正但循环数显著减少。

## 6. 结论

1. **做 T 可行**。在长江电力这类标的上，纪律性挂单能贡献约 **2.38%/年** 的成本降低。
2. **收益来源是纪律与成本，不是预测**。2.38%/年 几乎全部来自「挂单成交 → 反手」的机械结构
   与低交易成本，与任何预测能力无关。
3. **预测端剩 22pp 的空间，但没有可用的钥匙**。完美选单值 +22.24pp/年，
   而波动率类特征一个也抓不住（AUC 0.51~0.64，捕获率 2.1%）。
4. **优先序：选标的 > 选通道 > 调参**。参数调优的天花板很低（δ、K 的敏感区间已经很窄），
   而通道从 A 股换到 ETF/可转债直接 +1.75pp。
5. **不要加止损，不要挂太小的单**。前者砍掉赢家，后者被最低佣金吃掉。
6. **下一步应做跨标的验证，而非继续加因子**。目前只有 1 只标的、725 个交易日；
   若 2.38%/年 只是个例，后续所有精细化工作都没有地基。

## 9. 研究架构重构：三层职责分离

本节记录研究框架的一次根本性整理。前述第 1~8 节的全部实证结论**依然成立**，
但其定位需要重新表述：它们回答的是第三层的问题，前两层尚未建立。

### 9.1 核心认识

本研究实际做的不是「预测明天涨还是跌」，而是：

> **已经决定这个资产值得持有之后**，估计次日大概率可触及的价格区间，用这个区间安排买卖单；
> 而**是否值得持有**，由更慢周期的估值 / 性价比体系决定。

这两个问题必须彻底分离。此前把 PE、股债比、股息率与次日振幅做相关性分析，
属于经济逻辑上的错位——PE 回答的是「该不该持有它」，不是「明天振幅是多少」。

因此 **PE 与未来振幅相关性 ≈ 0 是职责分离正确的证据，不是 PE 无价值的证据**。

### 9.2 三层架构

| 层 | 回答的问题 | 变量 | 时间尺度 |
|---|---|---|---|
| 1 资产配置层 | 值不值得持有 | PE / PB / DY / FCF Yield 历史分位 | 年级别 |
| 2 仓位择时层 | 现在持多少 | 股债收益差、权益风险溢价、替代资产收益 | 月 / 季度级别 |
| 3 交易执行层 | 明天挂在哪里做 T | HV / ATR / 振幅分布 / 跳空 / 量 | 日级别 |

慢变量 → 决定「持不持有、持多少」；快变量 → 决定「明天挂多远」。
**是分层决策，不是互相预测。**

### 9.3 估值：绝对与相对是两个独立维度

**绝对性价比**（只看资产自身）：PE 历史分位、股息率历史分位、FCF yield。
回答「这个东西自己现在便不便宜」。

**相对性价比**（与其他资产比）：股息率 − 10Y 国债、盈利收益率 − 10Y 国债。
回答「虽然它不便宜，但还有没有比它更好的资产」。

二维矩阵：

| | 相对便宜 | 相对贵 |
|---|---|---|
| **绝对便宜** | 最有吸引力区域 | 可持有，但竞争资产更强 |
| **绝对贵** | 可被低利率环境支撑 | 性价比最低区域 |

「绝对贵 + 相对便宜」是近年低利率环境最常见、也最容易误判的状态：
PE 处于历史 80% 分位看似很贵，但股息率 − 国债收益差仍然不差。
此时结论不应是「PE 高 → 清仓」，而应是
**长期预期收益下降故降低仓位，但因替代资产收益率同样很低，不必然完全退出**。

抽象形式：

```
ERP_asset ≈ E(R_asset) − R_f
E(R) ≈ DividendYield + EarningsGrowth + ValuationChange
```

### 9.4 对框架的五点修正

**(1) 绝对估值的两个分位是共线的。**
DY = 分红率 / PE。分红率稳定时，PE 分位 ≈ DY 分位的倒数，
把二者加权求和等于把同一信号算两遍，权重 w₁ 会失真。
真正独立的第三维是 **payout ratio 自身的偏离**：PE 升而 DY 未降，说明分红率提高
（可能是基本面变好，也可能是利润下滑下的被动提高）。这个 divergence 才是增量信息。

**(2) E(R) 分解中「估值回归 −2%」不能当作输入。**
前两项（DY、长期增长）可测，第三项是残差。把 −2%/年 写进去，
等于假设 PE 一定均值回归且回归速度已知——这本身就是待预测的对象。
且 5 年 PE 分位在 725 天样本内几乎不变，是极慢变量，样本内无法验证。
**建议：ERP 以当前可观测的 DY − R_f 为主项，估值回归只作情景假设做敏感性分析。**

**(3) 分位数不等于档位。**
项目 B 输出分位分布是正确的，但不能直接「P25 挂一档、P50 挂二档」。
最优档位是期望最大化问题的解：

```
max_d  P(fill | d) × E[payoff | fill, d] − cost(d)
```

更深的档位赔率高但成交率低，且三档共享 K 额度，是联合优化而非独立取值。
实测最优 δ = 1.3%（δ<0.8% 被成本吃光，δ=2.0% 循环数骤降）
正是这个期望最大化的结果，不是任何标称分位。
**分位分布是输入，档位选择是在分布上再做的第二层优化。**

**(4) 慢变量应调的不只是底仓比例，还有买卖不对称。**
做 T 的下行尾部风险来自「持续单边下跌 + 估值压缩」——
此状态下买单不断成交、卖单不成交，T 引擎本身变成被动加仓。
故 ValueScore 应映射到 **(Kb, Ks)** 而非单一百分比：

| 估值状态 | 买卖额度 |
|---|---|
| 便宜 | Kb > Ks（愿意接货） |
| 正常 | Kb = Ks |
| 贵 | Kb < Ks（更愿意派发，不接） |

`simulate()` 已支持 `Kb` / `Ks` 分别传参，可直接验证。

**(5) 「下跌有限」必须从先验改为可测的条件尾部。**
不能写「它是水电所以跌不动」。
应表述为：其现金流稳定性与分红属性，使其历史上表现出较低的基本面尾部风险，
**但价格仍可能发生明显回撤**；低波 ≠ 不会大跌，类债 ≠ 债券，高股息 ≠ 有下跌保护。
无风险利率上行叠加 PE 压缩完全可以带来显著跌幅。
真正提供保护的是估值体系对「何时必须降仓」的判断，不是行业标签。
可测量的替代形式：`P(未来 N 日回撤 > x% | 当前估值状态)`，并区分基本面尾部与估值尾部。

### 9.5 项目 A：估值状态机（慢变量）

- **输入**：PE_TTM 5 年分位、股息率 5 年分位、payout 偏离、DY − 10Y 国债、EY − 10Y 国债
- **输出**：`ValueScore = w₁·Absolute + w₂·Relative` →（底仓比例, Kb/Ks 不对称, 引擎开关）
- **状态**：Very Cheap / Cheap / Normal / Expensive / Very Expensive

**诚实性约束（必须先解决，否则会重蹈「反复试因子」覆辙）：**
年级别变量在 **725 天（≈3 年）、单标的** 样本上**不可验证**——
3 年只有 3 个非重叠年观测，任何分位阈值都是在拟合噪声。
项目 A 要产出「结论」而非「框架」，至少需要：
**10 年以上时间序列 + 10 只以上横截面标的**。
在此之前，项目 A 只能作为框架存在，不得据此调参。

### 9.6 项目 B：波动分布模型（快变量）

完全不看估值。

- **目标变量**（上下行必须分开）：

```
Down_t = (C_{t−1} − L_t) / C_{t−1}
Up_t   = (H_t − C_{t−1}) / C_{t−1}
```

  预测 `(H−L)/C_{t−1}` 会丢掉最需要的信息——红利低波资产的上行与下行分布
  并不对称（趋势上涨期上行尾巴更长，下跌期下行尾部突然变厚）。

- **特征**：昨日振幅、HV5/20/60、ATR14、隔夜跳空、成交量、指数波动、行业波动
- **输出**：明日下行 / 上行的 10/25/50/75/90 分位（**预测分布，不预测点值**）
- **评估**：分位数校准（实际命中率是否等于标称分位）+ 区间锐度，
  用 **pinball loss**，不用相关系数

### 9.7 Oracle 实验的重新表述

原问题「PE 能不能预测波动」是错位的。正确的问题是：

> **在已经决定持有这只资产的前提下，如果我能更准确地知道次日上下波动分布，
> 究竟能额外降低多少持仓成本？**

对应四档递进实验（固定底仓、固定 K、固定成本，只放开信息）：

| 档 | 档位来源 | 含义 |
|---|---|---|
| L0 | 固定百分比距离 | 基准（2.38%/年） |
| L1 | 无条件历史分位 | 分布信息，无 conditioning |
| L2 | 波动模型条件分位 | **可捕获的执行效率提升 = L2 − L1** |
| L3 | 明日真实 Up / Down | 上界（剩余空间 = L3 − L2） |

`UP` / `DOWN` 序列已在 `scripts/t_sim_core.py` 中构建，可直接驱动该实验。
